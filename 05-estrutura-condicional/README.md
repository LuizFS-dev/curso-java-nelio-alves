# Módulo 05: Estrutura Condicional

*Curso de Java e POO - Prof. Nélio Alves*
*Data de execução: Maio de 2026*

Nesta etapa do curso, o foco foi sair da execução linear e aprender a controlar o fluxo do programa através de desvios condicionais. Pratiquei a tomada de decisões no código usando blocos if-else, tratamento de intervalos numéricos e a aplicação prática de operadores lógicos e relacionais.

## Exercícios Resolvidos

* [Exercicio01.java](./src/Exercicio01.java) - Verificação simples se um número inteiro lido é negativo ou não.
* [Exercicio02.java](./src/Exercicio02.java) - Leitura de um valor inteiro para determinar se ele é par ou ímpar usando o operador de resto.
* [Exercicio03.java](./src/Exercicio03.java) - Validação se dois números informados são múltiplos entre si, tanto em ordem crescente quanto decrescente.
* [Exercicio04.java](./src/Exercicio04.java) - Cálculo da duração de um jogo em horas, tratando a lógica condicional de eventos que começam em um dia e terminam no outro.
* [Exercicio05.java](./src/Exercicio05.java) - Implementação de um menu de produtos onde o programa recebe o código e a quantidade de um item para calcular o valor final da conta com base em uma tabela de preços.
* [Exercicio06.java](./src/Exercicio06.java) - Checagem de faixas numéricas sequenciais para identificar em qual intervalo um valor real se encontra ou se está fora deles.
* [Exercicio07.java](./src/Exercicio07.java) - Leitura de dois valores com uma casa decimal representando coordenadas (x, y) para classificar o posicionamento do ponto no plano cartesiano (quadrantes, origem ou eixos).
* [Exercicio08.java](./src/Exercicio08.java) - Lógica de cálculo de imposto de renda baseada em faixas salariais e tributação progressiva cumulativa.
* [TesteExcedente.java](./src/TesteExcedente.java) - Exercicio feito durante a vídeo aula para seguir a linha de raciocínio do prof. Nélio.
* [TesteSaudacao.java](./src/TesteSaudacao.java) - Exercicio feito durante a vídeo aula para seguir a linha de raciocínio do prof. Nélio.

## Conceitos Compreendidos

* Estruturação de condicionais encadeadas (`if`, `else if`, `else`) para evitar redundancias.
* Aplicação combinada de operadores lógicos (`&&`, `||`) e relacionais para validação.
* Resolução de problemas com regras de negócio baseadas em tabelas de preços e faixas progressivas de cálculo (como o [desafio do Imposto de Renda](./src/Exercicio08.java)).
