# Módulo 04: Estrutura Sequencial

*Data de execução: Maio de 2026*

Nesta etapa, foquei em praticar a lógica linear mais básica do Java: captura de dados com Scanner, operações matemáticas básicas e formatação de saída no console.

## Exercícios Resolvidos

* [Exercicio01.java](./src/Exercicio01.java) - Captura simples de dois números inteiros e exibição da soma.
* [Exercicio02.java](./src/Exercicio02.java) - Cálculo da área de um círculo usando Math.PI e Math.pow com controle de casas decimais.
* [Exercicio03.java](./src/Exercicio03.java) - Manipulação de operadores aritméticos para calcular a diferença de produtos.
* [Exercicio04.java](./src/Exercicio04.java) - Cálculo de salário multiplicando horas trabalhadas por valor-hora.
* [Exercicio05.java](./src/Exercicio05.java) - Leitura de dados (código, quantidade e preço de peças) para retornar o valor total a pagar.
* [Exercicio06.java](./src/Exercicio06.java) - Entrada de três valores reais usada para calcular a área de cinco formas geométricas.

## Conceitos Que Entendi Aqui

* Uso do `Scanner` (`nextLine`, `nextInt`, `nextDouble`) e o tratamento de quebras de linha no terminal.
* Aplicação do `printf` com as máscaras `%.2f` e `%.4f` para arredondamento de valores decimais.
* Configuração do `Locale.US` para forçar o ponto flutuante padrão americano no console.
