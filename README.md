# Trilha de Aprendizado: Java Completo e Programação Orientada a Objetos

Repositório dedicado ao desenvolvimento de fundamentos de lógica, arquitetura de software e consolidação dos pilares da Programação Orientada a Objetos (POO) utilizando Java. 

O objetivo deste projeto é documentar de forma prática a evolução desde os conceitos sequenciais mais básicos até desafios complexos de manipulação de memória, encapsulamento estruturado e algoritmos autônomos.

---

## Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 21+)
* **Ambiente de Desenvolvimento:** Visual Studio Code (VS Code)
* **Controle de Versão:** Git / GitHub

---

## Organização do Repositório

O projeto é estruturado em módulos progressivos. Cada diretório possui sua própria documentação detalhada (`README.md`) explicando os desafios resolvidos e as competências técnicas fixadas:

* **[01-primeiro-projeto](./01-primeiro-projeto/) ao [03-terceiro-projeto](./03-terceiro-projeto/)** - Configuração de ambiente, estruturas de teste e fluxo inicial de compilação.
* **[04-estrutura-sequencial](./04-estrutura-sequencial/)** - Lógica linear, entrada de dados (`Scanner`), formatação de saída e tratamento de pontos flutuantes.
* **[05-estrutura-condicional](./05-estrutura-condicional/)** - Controle de fluxo baseado em desvios condicionais compostos e encadeados.
* **[06-estrutura-repetitiva-for](./06-estrutura-repetitiva-for/)** - Loops com contagem predefinida e iterações cumulativas.
* **[06-estrutura-repetitiva-while](./06-estrutura-repetitiva-while/)** - Loops baseados em condições de parada dinâmicas. *Inclui o projeto autônomo do Relógio Fixo Internacional (Plano Cotsworth).*
* **[07-desafio-material-apoio](./07-desafio-material-apoio/)** - Transição entre a lógica estruturada e os conceitos iniciais de modularização.

---

## Projetos de Destaque

Além da grade padrão de exercícios, este repositório abriga implementações autorais construídas para testar limites de lógica e curiosidade técnica:
1.  **Simulador Plano Cotsworth (Pasta While):** Um motor de clock baseado em loops infinitos gerenciados por Threads (`Thread.sleep`) para simular o funcionamento histórico de um calendário de 13 meses com dias extras de transição anual.
