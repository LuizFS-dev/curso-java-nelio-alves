# Módulo 06: Estrutura Repetitiva (For)

*Curso de Java e POO - Prof. Nélio Alves*
*Data de execução: Junho de 2026*

Módulo focado na estrutura de repetição (`for`). Pratiquei a construção de loops, ideal para processamento de intervalos definidos, sequências numéricas e contagens regressivas ou progressivas.

## Exercícios Resolvidos

* [Exercicio01.java](./src/Exercicio01.java) - Filtro de intervalo numérico para identificar e exibir apenas os valores ímpares menores ou iguais à entrada.
* [Exercicio02.java](./src/Exercicio02.java) - Verificação de valores dentro e fora de um intervalo ([10,20]) no final mostra o total dentro e fora.
* [Exercicio03.java](./src/Exercicio03.java) - Cálculo de médias ponderadas para múltiplos conjuntos de dados reais (`double`).
* [Exercicio04.java](./src/Exercicio04.java) - Tratamento de divisões entre pares de números, aplicando validação para evitar heresias.
* [Exercicio05.java](./src/Exercicio05.java) - Cálculo matemático de fatorial simples utilizando estruturas multiplicativas cumulativas.
* [Exercicio06.java](./src/Exercicio06.java) - Algoritmo para cálculo e exibição de todos os divisores de um número inteiro informado.
* [Exercicio07.java](./src/Exercicio07.java) - Processamento de linhas numéricas exibindo o índice atual, seu quadrado e seu cubo.
* [TesteDoWhile.java](./src/TesteDoWhile.java) - Tentativa de implementar um loop while antes do próximo módulo após me lembrar do fundamento em portugol lecionado pelo Gustavo Guanabara.
* [TesteFor.java](./src/TesteFor.java) - Tentativa de entender a lógica extraída de outra IDE antes de prosseguir com a vídeo aula.

## Conceitos Compreendidos
* Inicialização, condição e incremento encapsulados em uma única linha de comando.
* Manipulação de variáveis acumuladoras (somas e multiplicações cumulativas).
